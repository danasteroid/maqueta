# AquaPack Huaraz

Maqueta tridimensional interactiva y desarmable basada en las referencias proporcionadas.

Permite mover 19 piezas independientes, abrir la tapa, orientar cada pieza, volver a armar el conjunto y explorar la vista con el mouse.

## Abrir en la computadora

Abre `index.html` con Chrome o Edge. El archivo incluye las dependencias y funciona sin internet.

## Publicar en GitHub Pages

1. Crea un repositorio público llamado `aquapack-3d` en tu cuenta de GitHub.
2. Sube los archivos de esta carpeta directamente a la raíz del repositorio, con `index.html` en la raíz.
3. En **Settings → Pages → Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama **main**, la carpeta **/(root)** y pulsa **Save**.
5. Espera a que GitHub muestre el enlace publicado en esa misma sección.

La maqueta utiliza Three.js, incluido dentro de `index.html`. Consulta `THIRD_PARTY_NOTICES.txt` para su licencia.

Las formas, conexiones y capas del filtro son ilustrativas. La maqueta no sustituye planos de fabricación ni validaciones de funcionamiento del equipo.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
